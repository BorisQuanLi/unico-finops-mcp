# Contributing to UnicoFinOps

We welcome contributions! This project is built with the **Model Context Protocol (MCP)** and adheres to modern FinOps standards.

## Development Standards
1. **Branching:** use `feature/` branches.
2. **Review:** All PRs are reviewed by **CodeRabbit** (AI) and human maintainers.
3. **Testing:** Please ensure `pytest` passes before submitting.
